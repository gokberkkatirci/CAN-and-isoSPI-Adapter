# Checked references

Access date: **2026-11-07**. Manufacturer documentation supports technical claims; JLCPCB listings support only observed procurement information. Web pages and stock can change. Exact source revisions must be archived or hashed at design freeze where redistribution permissions permit. No restricted ADI design package has been obtained.

1. Arduino, *Nano R4 datasheet*, ABX00142/ABX00143, retrieved copy marked modified 03/11/2026. Used for board interfaces, logic voltage, power, recovery and mechanics. [Official PDF](https://docs.arduino.cc/resources/datasheets/ABX00142-datasheet.pdf). Also [Nano R4 with headers, ABX00143](https://store.arduino.cc/products/nano-r4-with-headers). A prior retrieved copy had an older modification date; check the actual revision at freeze.
2. Arduino, *ArduinoCore-renesas, NANOR4 variant*. Official source, mutable main branch; pin declarations are supplementary to the board pinout. [pins_arduino.h](https://github.com/arduino/ArduinoCore-renesas/blob/main/variants/NANOR4/pins_arduino.h). Pin the installed core release for firmware integration. [Official schematic](https://docs.arduino.cc/resources/schematics/ABX00142-schematics.pdf): exact power path/footprint review remains necessary; extracted PDF text alone is insufficient.
3. Renesas, *Flexible Software Package: CAN (r_can)*, online documentation retrieved as release 6.6.0. Supports Classical CAN standard/extended frame and up-to-1-Mbit/s capability; does not verify our firmware throughput. [Documentation](https://renesas.github.io/fsp/group___c_a_n.html).
4. Analog Devices, *ADBMS6821/ADBMS6822 Single/Dual isoSPI Transceiver*, Rev. B. Used for supply ranges, operating modes and signal behavior. [Datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/adbms6821-adbms6822.pdf).
5. Analog Devices, *Evaluating the ADBMS6822 Dual isoSPI Adapter*, UG-2188, Rev. 0, 2024. Used for dual-port/shared-SPI architecture and configuration approach. [User guide](https://www.analog.com/media/en/technical-documentation/user-guides/eval-adbms6822-ug-2188.pdf).
6. Analog Devices, *ADBMS1818 18-Cell Battery Monitor with Daisy Chain Interface*, Rev. B. Used for 1-Mbit/s isoSPI and reversible-chain capability. [Datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/adbms1818.pdf).
7. Analog Devices, *ADBMS6832/ADBMS6833 18-Channel or 16-Channel Multicell Battery Monitors*, Rev. SpC, public short datasheet. Supports advertised 2-Mbit/s interface; insufficient for full hardware/timing approval. [Short datasheet](https://www.analog.com/media/en/technical-documentation/data-sheets/adbms6832-6833.pdf).
8. Texas Instruments, *ISO1042 isolated CAN transceiver*, product page linked datasheet Rev. F at this check. Used for physical-interface and isolation component capabilities. [Product and datasheet](https://www.ti.com/product/ISO1042). These are not ratings for the assembled adapter.
9. Bourns, *SM91801AL BMS Planar Transformer*, four-page datasheet. Used for 1,000-V-DC working rating, basic insulation, 1:1 ratio, environmental qualifications and package. [Datasheet](https://www.bourns.com/docs/product-datasheets/sm91801al.pdf). Corroboration: *New Product Release IC24021*, 28 February 2024, [manufacturer bulletin](https://bourns.com/docs/technical-documents/featured-product-bulletins/Bourns_IC24021_SM91801AL_NPR.pdf). Confirm latest drawing/material conditions before layout.
10. Pulse Electronics, *HM2101NL product specification*. Used to distinguish its functional insulation from the Bourns basic-insulation choice. [Manufacturer page](https://productfinder.pulseeng.com/product/HM2101NL).
11. Texas Instruments, *SN6505B transformer driver* and related isolated-power application guidance. Candidate topology only. [Product](https://www.ti.com/product/SN6505B), [application note SBAA268B](https://www.ti.com/lit/an/sbaa268b/sbaa268b.pdf).
12. Würth Elektronik, *760390014 WE-PPTI Push-Pull Transformer*, revision 009.002, 2025-10-02. Supports turns ratio, magnetic characteristics and insulation test specification. No 1 kV continuous working rating for our CAN supply has been verified. [Datasheet](https://www.we-online.com/components/products/datasheet/760390014.pdf).
13. Texas Instruments, *TLV767* and *TPS2553*. Regulator/load-switch candidates; final electrical calculation pending. [TLV76750DGNR](https://www.ti.com/product/TLV767/part-details/TLV76750DGNR), [TPS2553](https://www.ti.com/product/TPS2553).
14. Nexperia, *PESD2CANFD24V-T CAN bus ESD protection*. Used for CAN protection shortlist. Verify exact ordered suffix and pulse conditions at freeze. [Product](https://www.nexperia.com/product/PESD2CANFD24V-T).
15. Phoenix Contact, *MKDS 1,5/3-5,08, 1715734* and two-position family member *1715721*. Used for terminal construction and manufacturer drawing/rating review. [1715734 product](https://www.phoenixcontact.com/en-us/products/printed-circuit-board-terminal-mkds-15-3-508-1715734), [1715734 PDF](https://www.phoenixcontact.com/us/products/1715734/pdf). Exact 1715721 drawing remains a footprint-review item.
16. E-Switch, *Product matrix*, EG switch family. Family-level screening only; exact EG1218 drawing still required. [Manufacturer catalogue](https://www.e-switch.com/wp-content/uploads/2023/03/Rev4_Final_2023_ESWProductMatrix.pdf).
17. JLCPCB, *Parts library*, live searches for exact MPNs, 2026-11-07. Observed quantities/C-codes are recorded in [components.md](components.md). A search-engine cached Bourns listing showed six units, while the live UI showed one twice; live UI was used. [Bourns category listing](https://jlcpcb.com/parts/2nd/Inductors_Coils_Chokes/Pulse_Transformers_2296?Manufacturer=BOURNS).
18. JLCPCB, *PCB capabilities*, *PCB assembly capabilities*, and *How to generate the BOM and centroid file from KiCad*. Used for planning the manufacturing workflow; service eligibility and export schema must be checked again at release. [PCB](https://jlcpcb.com/capabilities/pcb-capabilities/), [assembly](https://jlcpcb.com/capabilities/pcb-assembly-capabilities), [KiCad export](https://jlcpcb.com/help/article/how-to-generate-the-bom-and-centroid-file-from-kicad).

## Verification limits

This is a source-backed planning package, not a validated circuit. Full ADBMS6832 design/timing documentation, PCB insulation coordination, exact socket selection, remaining passives/protection, worst-case power calculations and physical tests are unfinished. Component certifications are not transferred automatically to the board. Manufacturer reference circuits inform the design but have not been copied as an already-verified PCB.
